## Topic: Link Model and Drawing

### Link Parametric Design:

<img width="1917" height="1017" alt="A6_Bracket_Link" src="https://github.com/user-attachments/assets/df7abb62-27d3-448e-9b92-467fcb790383" />

[Bracket Link CAD Model](A6_Link.SLDPRT)

For this Bracket Link I designed for the Bracket itself was based on the parameters that I calculated for the Bracket in A5 - Bracket Design. The goal for the Link was to make it compatible with Feature A of the Bracket. It was required to have running/slicing fit on Feature A. This mean that the tolerance had to be within the range of the classes RC1 - RC9. Looking at the Machinery Handbook, there are different tolerances that you can choose from based on how you want it to fit onto the part and its function.

### Reflection:

A lesson learned about ensuring part to part compatibility through tolerancing is understanding how you want the two parts to interact with each other. For this part, it is required to run or slide around the cylindrical feature. In this case, we want the tolerance to be between classes RC1 - RC9. Looking at the chart in the Machinery Handbook, it will show the different tolerances for each class that you can choose from that will fulfill the function needed. Another thing that I learned is that the material properties and their parameters have a huge effect on how these parts will be compatible with each other. There has to be a balance between both parts so that they don't fail on each other.
