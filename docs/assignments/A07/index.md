# A7 – FEA on Bracket

## Objective

- Use Finite Element Analysis (FEA) to improve the bracket design from previous assignments.
- Ensure high stiffness, strength, and lightweight optimization through iterative design.
- Conduct multiple FEA simulations, refining geometry based on results.
- Perform static stress analysis, including constraints, loading, and meshing selection.
- Interpret data by identifying max stress, displacement, and safety factors.
- Optimize the design by modifying geometry to enhance performance.
- Document the entire process with images, calculations, and insights.
- Reflect on key engineering lessons learned and time spent.


Project Description:

Your task is simply to create a high stiff, high strength, and lightweight component. Use Finite Element analysis to drive your decision making process throughout your design. Each step of the analysis and before you make geometric changes make sure the component’s results (stress/displacement/Safety Factor) converge on a 7% difference. Achieve this by modifying the number of elements. If after three attempts to converge use the stiffness and stress from the finer mesh size use the finest mesh size and proceed through the process.

## Reflection:

For this project, I was required to use Finite Element Analysis to assist with my design of the Bracket Design. While running a simulation on my design, I was able to make assumptions and make changes to the design to fit the requirements to make this design work properly. I made three different designs to test for the best design that fit the requirements that were needed for this project. While I assume that it did, I am not sure if it passed the requirements that makes this design function. 

I did learn a lot from this project that will help me learn and improve on my designing skills. For this project, there are many parts to it that I've learned along the way and took into consideration when making a design and ensuring that it functions properly. I learned that when making a design, you have to consider the material properties, the dimensions, and the load your design will undergo. When you run a simulation on the design, you will be able to test for the max stress, displacement, and the max strain of the design, which will help when designing for the real world. Using the Finite Element Analysis will help with many design purposes to ensure that your design will perform as you expect.
