# A8 – Gear Box Design

## Objective

- Design a gearbox that can be assembled and disassembled.
- Analyze and size input and output shafts for strength.
- Design journal bearings to support shafts.
- Create a gearbox housing with proper clearance and fastening.
- Use parametric CAD modeling to generate a final design.
- Document calculations, sketches, and lessons learned.

## Description:

Design a gearbox which can be assembled and disassembled. The spur gears have a gear ratio of 24:9 and are listed in the resource section. The output gear torque and speed are to be 1.25 in-lbf and 1100 rpm relative. The input (pinion,power-transmission) and output (gear, short shaft) shaft diameters are .125 and .25 inches respectively and each have a length of 1 inch. Use the appropriate equations in the Machinery’s Handbook for empirical units. The critical features of the gearbox include the shafts, and the journal bearings.

## Assumptions: 

- Assume appropriate strength of shafts, use Machinery’s Handbook.
- The gear train is ideal.
- The moment of the radial force from the gear train is small enough to be ignored.

## Note:

- The shafts are press fit through the hubs of the gears.
- Make sure there is enough clearance between the gears and the gearbox.
- Use a running sliding fit for the size of the hole for the shafts.

## Lessons Learned:

For this project, I learned how to calculate for the Input Torque, Max Torsional Shear Stress, and Diameter for the shafts that we needed to design on our own. I also learned how to calculate the Bearing Pressure, Velocity, PV Product, and Thickness. To solve for these parameters, I had to use Statics and look in the notes to find the equations for power transmission. With some help from Solids, I was able to make my calculations to find these parameters. As I continue to work in SolidWorks, I am getting more familiar with it to be able to design and make changes efficiently. When making an assembly in SolidWorks, it can get complicated, but I am becoming more comfortable with this software, so it is getting easier for me. Making drawings is still pretty complicated but overall, I have gotten the hang of SolidWorks. Most importantly, the biggest I can take away from this project is how we can make calculations and apply it to make a model that will be fully functional to the standards that you place on your design. By getting more practice like this project, I believe I will be able to make a design that will be functional and satisfy all the conditions.
